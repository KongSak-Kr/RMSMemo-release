# RMSMemo

화면 한쪽에 붙여 두는 연구실용 포스트잇 메모예요. 내 할 일, 우리 팀 일, 연구실 공용 일을 따로 적고,
팀·연구실 메모는 연구실 NAS로 다 같이 봐요. (Windows 전용)

## 받기

[**Releases**](../../releases/latest)에서 최신 파일을 받으세요.

- `RMSMemo_<버전>.exe` — 이것만 있으면 돼요. 더블클릭하면 설치되고 시작 메뉴에 **RMSMemo**가 생겨요. Python은 필요 없어요.
- `RMSMemo_<버전>.zip` — exe + 사용설명서

처음 켜면 이름, NAS 폴더(예: `\\NAS\연구실`), 팀을 물어봐요.

> "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누르세요. 서명 없는 사내 프로그램이라 처음 한 번 나올 수 있어요.

## 업데이트

한 번 설치하면 새 버전이 나올 때 앱이 알려 줘요. 설정에서 **자동으로 설치**를 고르면 글을 쓰고 있지 않을 때 알아서 바뀌어요.
